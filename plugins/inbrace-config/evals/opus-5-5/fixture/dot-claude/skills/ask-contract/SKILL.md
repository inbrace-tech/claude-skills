# Ask about a contract

The reviewer opens a chat about one contract and asks questions about it, often a dozen short follow-ups in a row.

- Read the clause file for the contract (`pnpm clauses:show <id>`) before the first answer.
- Quote the clause you rely on, with its section number.
- If a question needs the vendor's position, say that it needs the negotiation log and stop there.
- Think carefully before answering each question.
