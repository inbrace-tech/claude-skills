# Notes for Claude Opus 5.5

Written from Prompting Claude Opus 5.5 (https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-opus-5-5) during the September trial. The session-start hook adds these notes to sessions on Claude Opus 5.5.

## Latency

- For a clause lookup while the reviewer waits on the line, answer directly without deliberating.

## Clauses

- Quote clause text exactly, with its section number; never paraphrase inside quotation marks.
- Write dates as `YYYY-MM-DD` and amounts with their currency code.
