description: Review the current branch's diff before opening a pull request.
---

Review the diff of the current branch against `main`.

- Check the change against the conventions in `docs/claude/conventions.md`.
- Be conservative: only report high-severity issues, and leave out nits and style.
- Group the findings by file, with `file:line` for each.
- End with the commands the author should run before pushing.
