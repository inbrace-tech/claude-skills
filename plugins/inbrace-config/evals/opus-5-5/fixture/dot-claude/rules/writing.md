# Writing redlines, summaries and reports

Deliver what was asked, at the scope intended. Make routine judgment calls yourself, and check in only when different readings of the request would lead to materially different work.

- Use the playbook's wording for standard positions; don't rephrase them.
- Name clauses by section number and title, as in "12.3 Limitation of liability".
- Write amounts with their currency code and dates as `YYYY-MM-DD`.
